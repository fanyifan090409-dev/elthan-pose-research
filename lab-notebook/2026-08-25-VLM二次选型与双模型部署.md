# 2026-08-25 VLM 二次选型与双模型部署

## 选型结论
- 原计划 Qwen3-VL-32B BF16 (TP=2) 被否：权重 64GB = 双卡总显存，无 KV 空间，装不下。
- 定版双模型 A/B 路线：
  - 在线主力：Qwen3-VL-8B-Instruct（BF16，GPU1，:8000）
  - 质量对照：Qwen2.5-VL-32B-Instruct-AWQ（INT4 ~20GB，GPU0，:8001）
- Qwen3-VL-30B-A3B-FP8 需 TP=2 占双卡，训练期不可用，暂缓。

## 环境
- conda env vlm = Python 3.12 + vllm 0.27.1 + torch 2.13.0+cu130；驱动 580.159.03（CUDA 13.0）。
- 权重：/home/ubuntu/isef/models/qwen3-vl-8b-instruct、qwen2.5-vl-32b-instruct-awq（hf-mirror 下载）。
- 服务：tmux 会话 vlm8 / vlm32；脚本 scripts/serve_qwen3vl8b.sh、serve_q25vl32b.sh；日志 logs/vllm_serve_*.log。

## 踩坑记录
1. py3.10 环境 flashinfer/comm/fd_exchange.py 语法不兼容 → vlm 环境必须 py3.12。
2. FlashInfer JIT 在 RTX 5090 (sm_120) 误报 "requires sm75 or higher" → 启动须带
   VLLM_USE_FLASHINFER_SAMPLER=0、VLLM_ATTENTION_BACKEND=FLASH_ATTN、TORCH_CUDA_ARCH_LIST=12.0。
3. huggingface_hub xet 协议走 cas-server.xethub.hf.co 返回 401 → 下载须 export HF_HUB_DISABLE_XET=1 + HF_ENDPOINT=https://hf-mirror.com。
4. ModelScope 无 Qwen3-VL 系列 AWQ/GPTQ；Qwen2.5-VL-32B-Instruct-AWQ 有官方仓。
