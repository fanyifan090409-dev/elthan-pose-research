## 网上调研补充结论（本次搜索）

- Skyline 官方兼容性：[组件支持](https://developers.weixin.qq.com/miniprogram/dev/framework/runtime/skyline/component.html)、[迁移兼容性](https://developers.weixin.qq.com/miniprogram/dev/framework/runtime/skyline/migration/compatibility.html) —— camera/canvas/live-player/video 均支持且原生组件同层渲染；不支持桌面端/企业微信；原生导航栏不可用。
- 审核驳回高频原因汇总（2026）：功能不完整、测试数据残留、隐私协议缺失、类目不符、诱导行为 —— 与本清单 18-24 条一致。
- miniprogram-ci 常见失败：密钥格式/权限、IP 白名单、开发者未绑定 —— 与 29/30 条一致。
- 隐私保护指引自 2023-09-15 起强制，未声明 API 真机不可用 —— 11 条是本项目上线前第一优先。
