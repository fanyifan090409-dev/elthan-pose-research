## 六、证据边界与使用红线

1. **不重复计数**：#15 与 #16 是同一调查（同 1,111 人、同作者组）的两篇论文，引用时合并为一条证据。
2. **不夸大测量系统**：#2（Foot4D）是多视角深度相机，不是单目；#3/#5 显示单相机与动捕信度有限——论文中效度声明只写「单目视频经校验的 2D 额状面角」，不写「等同于 3D 动捕」。
3. **不迁移人群结论**：#20 是中老年 OA 队列；#17 是丹麦登记库；#18 是沙特样本——均只作背景参照，各自注明人群。
4. **不选择性引用**：#11（组间无显著差异）与 #12（2D/3D 时机不一致）是「不利」证据，必须写进论文局限性，这恰是预注册研究的可信度来源。
