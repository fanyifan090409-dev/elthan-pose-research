## 1. M1 遮挡分层 mAP

### 1.1 分层口径

- 定义：对每个 GT 关键点按其可见性标记 v 归入一层，在该层内独立计算 OKS AP。
- 层级：v=2 可见 / v=1 遮挡 / v=0 缺失（不可见）。
- v=0 层只报告、不参与任何模型排名（该层只能靠猜，数值接近 0，但保留作协议完整性证据）。
- 各数据集 v 语义（**G2/G4 必须核验转换后仍保留**）：
  - CrowdPose val：v=1 即遮挡标记，与 COCO 语义一致；**已核验（2026-09-30，M1 实测）**：官方 json 为 14 点，转换规则与训练严格同源——CrowdPose 0-11 → COCO 5-16，head_top/neck 两点丢弃（带走 14570 个 v=1 + 2484 个 v=0，属映射裁剪而非 v 破坏），COCO 0-4 面部 = v=0 假点，越界 v>0 降 v=0（官方 json 仅 8 点触发）。转换后 GT（crowdpose_val_gt17.json）v 分布 0/1/2 = 80898/37020/27041（8527 实例），12 个映射点的 v=1 完整保留；
  - OCHuman test：原始标注 v∈{1,2,3} 为三级遮挡程度，YOLO 格式只有 0/1/2——**核验转换脚本当时的映射规则**，若已被压成两档则按实际可用层级报告并在论文注明；**已核验（2026-09-30）**：官方 test json 本身即 17 点 COCO 格式（0/1/2 = 10688/9300/44935），直通保留；M1 的 GT 重映射 image_id = int(文件名 stem)（ultralytics preds 口径）并剔除缺失图 001287.jpg → 2230 图 / 3818 实例；
  - COCO val：**已核验（2026-09-30，M1 实测）**：有 v=1 标注，GT 关键点 v 占比 2/1/0 = 55.42%/7.75%/36.83%（person_keypoints_val2017.json），三层均可报告、Δ_occ 可计算；原「无 v=1」判断作废。

### 1.2 OKS 阈值与计算口径

- 沿用官方 OKS 口径：阈值 0.50:0.95 共 10 档，步长 0.05，逐阈值 AP 取均值，报告 mAP50-95(P)。
- **口径修正（2026-09-30 实证）**：「官方」指 pycocotools 2.0.11 keypoints 协议（官方发布数口径），不是 ultralytics val 内部 PoseMetrics——两者差 20+ 点的根源：pycocotools 把 num_keypoints=0 的 GT 标 ignore、OKS 对这类 GT 用双倍 bbox 距离兜底、maxDets=20。论文报告一律用 pycocotools 口径，official.json 双段存档（posemetrics + pycoco）。
- 分层实现：先按官方流程为每对 (det, GT person) 算逐关键点 OKS 贡献 d_i，层内 AP 只累计该层 GT 关键点的 d_i；人员匹配（TP/FP 判定）仍按全关键点 OKS 进行（不改变匹配逻辑，只改变统计口径）。
- **层召回天花板（2026-09-30 实测注记）**：层 AP 的 recall 分母 = 全部 GT 人员（n_gt），无该层关键点的 GT 人员永远无法贡献该层 tp → 每层报告「有该层关键点的 GT 人数占比」（gt_person_frac）作解释性证据。CrowdPose v2 层受 14→17 映射裁剪影响（head_top/neck 未映射），gt_person_frac 仅 0.591，v2 层 AP 系统性低估——论文须注明该伪影，v2/v1 层间比较在 CrowdPose 上以 Δ_occ 为准（Δ_occ 不受影响）。
- 每层报告两样：该层 mAP50-95(P) + 该层 GT 关键点占比（样本量）。占比 <1% 的层标注「样本不足，仅参考」。
- 与官方全量对照：全量 mAP50-95(P) 与 official.json 的 pycoco 段（pycocotools 2.0.11 原库对同一份 preds.json 补算）差 >0.5 点即判 harness 有 bug（门禁 1）。

### 1.3 RQ1 分析口径

- 输出「全量排名 vs 分层排名」对照表：两模型在 v=2 层与 v=1 层的排名是否翻转；
- v=1 层 mAP 与全量 mAP 的差（Δ_occ = mAP_v1 − mAP_full）作为「全量掩盖遮挡差异」的量化证据。

## 2. M2 角度误差

### 2.1 关节定义（COCO17 索引，0-based）

| 关节 | 顶点 | 射线端点（近端, 远端） |
|---|---|---|
| 左肘 | 7 | 5, 9 |
| 右肘 | 8 | 6, 10 |
| 左膝 | 13 | 11, 15 |
| 右膝 | 14 | 12, 16 |

内角公式：a = p_近端 − p_顶点，b = p_远端 − p_顶点，θ = arccos( (a·b)/(|a||b|) )，弧度转度。|a| 或 |b| < ε（ε=1e-6）的实例剔除。

### 2.2 有效性掩码

- GT 角度：三点 GT v 均 >0 才计入（真值定义域）；
- 预测角度：同三点 GT v 均 >0 且预测置信度 >0 才计入（保证 GT/pred 同域可比，不引入预测缺失的偏差）；
- 逐实例误差 e = θ_pred − θ_gt，报告 RMSE、MAE、P95、误差分布直方图（±5° 桶）；
- 按顶点关节 GT 可见性分层报告：膝/肘 v=2 与 v=1 两档（回答「角度误差是否被遮挡放大」，与 M1 联动）。

### 2.3 代偿检出率（膝内扣）

- 2D 代理量（无额外面向数据时的定义）：膝内扣角 φ = 髋→膝向量与髋→踝向量在图像平面的夹角（膝点偏离髋踝轴线的程度）。φ 大 = 内扣。仅对两点髋、膝、踝三点 v 均 >0 的实例计算。
- 阈值锚点：文献量级参照 Mendonça 膝外翻 FPPA 16.01–17.35°（**仅作量级参照**，G5 需复核该文献原文口径是否与 2D 图像代理可比；论文中如实声明 2D 代理 ≠ 临床 FPPA）。
- 检出定义：φ_pred 与 φ_GT 分别对阈值 τ 二值化（默认 τ=15°，敏感性分析 τ∈{10°, 17°}）。
- 报告指标：以 GT 为金标准的分类一致性——检出灵敏度、特异度、Cohen's κ。**不报告绝对检出率**（静态数据集视角混杂，绝对率无意义，一致性才是协议能测的量）。

## 3. M3 时序抖动

### 3.1 数据与匹配

- PoseTrack val 视频，逐帧独立推理（无追踪、无跨帧信息）；
- 人员匹配：每帧预测与 GT 按全关键点 OKS 匈牙利匹配（同 M1 口径），只统计连续 ≥10 帧有匹配的轨迹段；
- 归一化：以 GT 人框尺度 s_t = sqrt(w·h) 归一化所有位移（与 OKS 尺度口径一致）。

### 3.2 三个指标（对每个关键点、每条轨迹计算后取均值）

1. **帧间位移** d_t = ‖p_t − p_{t−1}‖₂ / s_t：报告均值与 P95（总量级证据）；
2. **抖动** j_t = ‖p_t − ŝ_t‖₂ / s_t，ŝ 为因果 5 帧中值滤波轨迹：专测高频噪声（RQ3 核心指标）；
3. **跳变率**：d_t > τ 的帧占比，默认 τ=0.10（人框尺度 10%），敏感性 τ∈{0.05, 0.20}。

### 3.3 OneEuro 前后对比

- 离线对 p_t 施加因果 OneEuro 滤波（归一化坐标空间）：参数固定 min_cutoff=1.0、beta=0.007、d_cutoff=1.0（Casiez 默认，G5 复核）；
- 平滑后重算 1–3 三指标 + 全量 OKS mAP 变化（平滑的精度代价）；
- 报告表格：每关键点 × {原始, 平滑} 三指标。
- **实证注（2026-10-01，两模型一致）**：归一化空间滤波后反归一化会把 GT 人框逐帧尺度噪声（|s_t/s_{t−1}−1| median 0.97%、P95 8.1%）重新注入像素域——实测抖动指标不降反升、AP 掉 0.13–0.29 点；对照口径「像素域直接滤波」零 AP 代价（±0.02 点内）换来三指标全面下降（jump_0.05 相对降 ~10%）。G2 双口径均记录（metrics.json m3.smoothed / m3.smoothed_px），论文主口径写作期定，表格注明滤波域。

## 4. 统计方案

- 模型比较：图像级（M1/M2）或轨迹级（M3）bootstrap 重采样 10,000 次，报告 Δ 的 95% 百分位 CI；CI 不含 0 判显著。
- 多重比较：比较清单在实验前固定（2 模型 × 3 数据集 × 层/关节/指标），属预注册口径，逐项报告 CI 不做全局族错误率修正，但清单全部如实列出（不挑结果）。
- RQ4 冗余性：三指标在模型×数据集×分层单元上的 Spearman 相关矩阵 + 每模型协议排名 vs 全量 OKS 排名的一致性（Kendall τ）。相关性高（|ρ|>0.8）的指标对在讨论中论证精简可能。
