# YOLO 源码优化方案（round6+ 路线）

> 2026-09-28 基于权威文献 + GitHub 调研（两条研究线并行完成）。
> 前置事实：数据平台期已到（round5-3 vs round5-2 零增益）、过拟合实验证明管线健康、消融证明遮挡增益全部来自 Tier-2 遮挡数据。

## 0. 结论先行

| 方向 | 调研后的裁定 | 优先级 |
|---|---|---|
| B1 解剖先验 loss | **强支持**：OKS-sigma 入 loss + 骨长/对称/角度，不确定性闭式加权，另设「手工 vs 可学习」对照防反方 | round6 论文主体（11 月） |
| B2 遮挡感知分支 | **改道**：文献一致指向「可见性加权 loss + 遮挡增广」，显式遮挡分支先例少；官方盖章 v 通道训练被忽略 | 随 B1 同轮做（B2'） |
| B3 骨干注意力 | **期望下调**：期刊+民间多源消融一致显示小模型收益 ≤0.9 点、插错位负优化 → 按负结果小节设计 | 消融（2 天） |
| B4 轻量骨干 | **改道**：优先 DWPose 式蒸馏（s→n），换 MobileNetV4 成本高；官方+社区确认无验证配方，全部自研 | 12 月起 |

总顺序不变：**评估 harness（度量基础）→ B1+B2'（round6）→ B3 消融 → B4 蒸馏**。

二轮调研核心收获：B1/B2' 从「推测有戏」升级为「官方盖章空缺 + 顶刊先例 + 民间无解」三重印证；「2D YOLO 系 + OKS/解剖 loss」顶刊空白仍在，round6 论文无直接撞车（详见第 6 节）。

## 3. 分方向源码改动方案

### B1：解剖先验 loss（`utils/loss.py` v8PoseLoss 内部改，不动 head/导出链）

1. **OKS-sigma 入 loss**：现有 OKS 型项 `(1−e^(−d²/2σ²A))·d²` 的 σ 按 OKS_SIGMA 逐关键点区分（现为统一值）——优化目标与评测指标对齐（官方空缺；评测侧自定义 sigma 的 PR 已合入，训练侧未做）。
2. **骨长一致性正则**：COCO17 点定义骨段（肩-肘、肘-腕、髋-膝、膝-踝、肩-髋、膝-肩对侧等），以躯干长归一化消除尺度歧义；批内统计骨长先验分布 → 预测骨长与先验的 L2/KL 软正则。按关键点数归一（民间经验：pose loss 不随点数缩放，~100 kpt 才学不动，17 kpt 无虞但归一保底）。
3. **对称性小权重项**：左右肩/髋/膝/踝高度差软惩罚。
4. **角度合理性项**：膝/肘弯曲角超出解剖范围 [0°,180°) 时惩罚；深蹲膝角可加数据集统计高斯先验（弱权重，康复综述显示 markerless 角度未达临床精度——权重必须保守）。
5. **四项权重用解析式不确定性加权**（2408.07985 闭式解），替代手工网格调参；加项后须重调总 pose 权重 12（民间经验：pose loss 主导总 loss）。
6. **「手工规则 vs 可学习结构 loss」对照**：SEAL-pose（2602.20051）是可学习路线先例，round6 消融里加一组对照，防审稿人反杀。
7. 消融协议：逐项开关（只 OKS-sigma / +骨长 / +对称 / +角度 / +可学习对照），同数据同配方（round5-2 init、有效 lr 0.005、30 epoch），三基准对拍；续训用 resume 时先核验起点权重（民间坑：resume+自定义 pretrained 会静默加载 pretrained）。

### B2'：可见性加权（替代显式遮挡分支）

1. 利用 (17,3) 第三通道：`w_v = v==2 ? 1.0 : (v==1 ? 0.5 : 0)` 加权 kpt loss——遮挡点半权重（不弃用，保留弱监督）。官方确认训练时 v 通道完全被忽略（#3409），这是真实空缺非锦上添花。
2. 遮挡增广双基线：ultralytics 内置 erasing（零成本）+ 肢体关节增广对照组（2410.09885，遮挡评测综述 10.11834/jig.230730 的分类支持）。
3. 备选升级 B2+（仅当 B2' 不够）：DWPose 式可见性预测头（复用 v 通道监督）；或 Pose Prior Learner 式无监督姿态先验（2410.03858，免标签）。
4. 评测：CrowdPose val / OCHuman test 为主指标（COCO 不许掉 >0.3 点）。

### B3：ECA 注意力消融（期望下调，按负结果小节设计）

- 多源消融一致：SE/CBAM/SimAM/ECA/PSA 五模块 FLOPs +18~42%、mAP 仅 +0.3~0.9（CSDN 民间消融），期刊小改小涨（PLOS ONE/Sci Rep）同向 → ±0.3 点内视为无效，作论文负结果小节材料。
- 落点必须是 C2f 输出位（社区共识：塞残差内部会截断梯度流，实测 mAP −1.2）；NCNN 需预验证 adaptive pool / hardsigmoid 算子（导出链回归必测 FP32/FP16/INT8 三档）。

### B4：蒸馏优先（等 #101 真机基准）

- 若 s 模型真机延迟不达标：DWPose 式两阶段蒸馏，teacher=round5-2 s，student=yolo11n-pose；MobileNetV4 替换仅在蒸馏精度不可接受时启动（训练重来 + 导出链重验成本高）。
- 方法参考补全：DistilPose（CVPR23 heatmap→tokenized 回归）、两阶段蒸馏+GNN（2508.11212）、跨域低分辨率 KD（2405.11448，对应手机低清竖屏场景）。
- 官方 KD 指南明确 pose「精度未验证」且仅限同代配对 → 全部自研，不指望官方工具。

## 5. 合规与风险

- AGPL：训练侧自用修改无碍；产品端模型经 NCNN 导出（权重非代码），推理用自研 wrapper，不分发修改后的 ultralytics 代码。
- 一稿多投分界：评估协议（A）/模型（B）/部署（C）若分别成文，保持方法学与实验数据分界（呼应论文申请路线）。
- 文献核验：调研中「CCP 坐标分类」经核实不存在已剔除；所有引用以上表 arXiv 编号为准。
- **评测口径警示**：默认 COCO sigma 过宽会致小数据集 mAP 虚高（#2543）；历史谱系值（0.505 等）基于默认口径，阶段 A 换自定义 sigma 后数值不可直接纵向对比，须双口径并报。
- **B1 审稿风险**：SEAL-pose 反方已设对照；康复综述（角度未达临床精度）要求 B1 权重保守、论文措辞不夸精度。
- **训练操作风险**：resume+自定义 pretrained 静默加载（#25812）→ 续训前核验起点权重；加 B1 各项后重调 pose 总权重 12。
- **端侧风险**：RK3588 pose INT8 有直接失败案例 → INT8 走校准协议且导出链回归必测 pose 三档。

### 6.3 二轮结论（对原方案的修订）

1. **B1 不变，新增两处**：①不确定性闭式加权（2408.07985）替代手工调四项权重；②round6 增加「手工规则 vs SEAL-pose 式可学习 loss」对照，防先验设计被审稿人用 SEAL-pose 反杀。
2. **B2' 不变**：官方盖章 v 通道训练缺失；erasing 之外加「肢体关节增广」对照组（2410.09885）。
3. **B3 期望进一步下调**：多源独立消融一致显示 YOLO 小模型注意力收益 ≤0.9 点且插错位负优化；保持「C2f 输出位 + ±0.3 阈值」，可作为论文负结果小节。
4. **B4 不变**：蒸馏证据链补全，但官方+社区一致确认无验证配方，自研预期坐实。
5. **「2D YOLO 系 + OKS/解剖 loss」顶刊空白仍在**：round6 论文定位（B1+B2'）无直接撞车，审稿风险主要来自 SEAL-pose 反方，需预先设计对照。
6. 新增廉价 trick 待排期：INT8 校准协议（#100 时做）、B1 后重调 pose 权重、续训 resume 核验脚本。
