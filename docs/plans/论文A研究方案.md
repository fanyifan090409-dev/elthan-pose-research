# 论文 A 研究方案（评估协议篇）

> 2026-09-29 定稿。用户已拍板：角度=GT 关键点推导、时序=下载 PoseTrack（不做协议-only 缩水版）。
> 缺口清单见 docs/plans/论文A评估协议-缺口清单.md。

## 研究目的

现有 2D 姿态估计主流评测协议（OKS mAP）存在三个盲区：**不区分遮挡、不测关节角度误差、不测时序稳定性**。本文提出一个统一的补充评估协议覆盖三盲区，在公开数据集上对代表性模型做基准分析，并开源 eval harness。

## 研究问题

- RQ1（遮挡）：全量 OKS mAP 是否掩盖遮挡场景的精度差异？按 v 分层后模型排名是否变化？
- RQ2（角度）：关节角 RMSE 能否区分 OKS mAP 接近的模型？角度误差对关键点误差的敏感度如何？
- RQ3（时序）：逐帧独立推理（无追踪）的时序稳定性差异有多大？OneEuro 平滑前后对比？
- RQ4（协议精简）：三指标间相关性如何，是否存在冗余？（协议设计的正当性论证）

## 方案定稿

| 指标 | 测量方法 | 数据 |
|---|---|---|
| 遮挡分层 mAP | 按 v 分层报告 mAP（v=2 可见 / v=1 遮挡 / v=0 不可见），与官方全量 OKS 对照 | CrowdPose val（v=1 标记）、OCHuman test（v=1/2/3 标记）；COCO val 作通用域对照 |
| 角度误差 | GT 关键点推导关节角（膝/肘）为真值，预测关键点算同角 → RMSE + 误差分布；代偿检出率用膝内扣 FPPA 阈值（文献锚点 Mendonça 16.01–17.35°，仅量级参照） | 同遮挡数据集（零额外标注） |
| 时序抖动 | 视频逐帧独立推理（无追踪），帧间关键点位移/跳变度量；借鉴 PoseTrack Jitter 概念适配单帧场景；OneEuro 平滑前后对比 | PoseTrack（MPII 官方申请下载，学术许可） |

**基准模型**：round5-3 best（数据轮最优）+ 官方 YOLO11s-pose pretrained。round6 模型**不进**本论文（分界，留给论文 B）。

## 贡献声明

1. 首个「遮挡分层 + 角度误差 + 时序抖动」统一补充协议（G5 文献检索确认 novelty 边界，若发现先例则相应收窄声明）
2. 开源 eval harness（分层 mAP / 角度 / 时序三模块，一次跑出全指标）
3. 现有模型在协议下的基准数字，暴露 OKS 盲区的量化证据（RQ1-3 的答案）
