# 01 数据篇：下载 / 格式转换 / 筛选配比

格式：**症状 → 根因 → 修法 → 出处**。数据集案例为 pose 训练，规则通用。

## 1. tar 解压报「not in gzip format」

- 症状：`tar -zxf` 报错，文件明明存在。
- 根因：分卷包是普通 tar 不是 gzip（如 PoseTrack18 分卷）。
- 修法：先 `file x.tar` 确认类型；普通 tar 用 `tar -xf`；分卷包先拼包校验再解压。
- 出处：PoseTrack18 分卷接收。

## 2. 官方下载链接失效，全量下载卡死

- 症状：数据集官方链接 404/超时，脚本重试无果。
- 根因：镜像失效、直连被墙；只验证了网页没验证下载链接。
- 修法：先小样（下载 1 个分卷/几张图）验证，再全量；失败走中转机下载后 rsync 训练机；留官方申请页兜底。
- 出处：CrowdPose images.zip 经 Mac 中转；PoseTrack 官方申请 + hyper.ai 兜底。

## 3. 格式转换裁剪改变层分布

- 症状：转换后遮挡层样本数比预期少，评测时层 AP 系统性偏低。
- 根因：源标注 14 点转 COCO 17 点只映射 12 点，未映射点（head_top/neck）带走的 v=1 样本随裁剪消失——是映射裁剪不是 v 破坏，但分布确实变了。
- 修法：转换脚本记录「每点映射表 + 裁剪前后各层计数」；报告注明层覆盖天花板（如 v2 层 GT 人占比仅 0.59）。
- 出处：CrowdPose 14→17 转换（build_gt17.py）；coco-val v2 层 gt_person_frac。

## 4. 先验判断被实测推翻（"这个数据集没有 v=1"）

- 症状：按"某标签层不存在"设计协议，实测发现存在。
- 根因：凭印象/文档判断标签分布，没跑真实统计。
- 修法：协议定稿前跑真实标签统计（各 v 层关键点占比/人占比），用实测数据落协议。
- 出处：COCO val 实测 v=1 占 7.75%，推翻「无 v=1」判断。

## 5. 占位关键点没做有效性掩码

- 症状：时序指标/角度指标算出大量垃圾值（0 坐标参与运算）。
- 根因：PoseTrack GT v=0 即 (0,0) 占位（34.4% 关键点），pred conf=0 同理；直接算角度/轨迹会把占位点当真实点。
- 修法：有效性掩码 = GT v>0 且 pred conf>0；无 bbox 的空壳 ann（全 v=0）直接跳过。
- 出处：M3 时序引擎（harness/temporal.py）。

## 6. 跨视频拼数据集时文件名 stem 撞车

- 症状：save_json 输出 image_id 对不上 GT，评测全错。
- 根因：多视频各自从 000001 起编号，逐视频 stem 重复；框架按文件名 stem 映射。
- 修法：stem 数值化重映射，image_id = vid*10000+frame 保证全局唯一（硬链接场不重复占盘）。
- 出处：PoseTrack 170 视频合并（build_posetrack.py，20161 图）。

## 7. 标签文件名前导零丢失

- 症状：标签读不到，指标假 0。
- 根因：`img2label_path` 只换扩展名，前导零在整型转换中丢失，label 文件名对不上。
- 修法：标签路径一律字符串拼接（zfill/原样），禁止整数往返；转换后抽样核对 img-label 一一对应。
- 出处：M3 首跑 posemetrics 假 0，修复后重跑推断。

## 8. 数据集可用性没先验证

- 症状：规划里列了数据集，临到用才发现版权/格式/规模不行。
- 根因：只看了论文/官网介绍。
- 修法：落地前实测：下载样张、看标注格式、数样本量、确认许可；不可用的（如 Yoga 系）果断砍掉，方案里保留备注即可。
- 出处：Yoga 数据集评估后弃用。

## 9. 多来源数据集筛选口径不统一

- 症状：不同来源数据质量参差，训练域偏移。
- 根因：手工/临时脚本各筛各的，无统一过滤标准。
- 修法：同一筛选脚本（参数化）跑所有来源；筛选条件（最小关键点数/置信度/裁剪规则）写入文档并进 git。
- 出处：CrowdPose/OCHuman/OTP 统一 screen_*.py 口径。

## 10. 标签转换的 id 重映射漏做

- 症状：评测匹配全错（GT 与 pred 的 id 空间不一致）。
- 根因：合并多个源标注时类别 id/图片 id 空间冲突。
- 修法：转换脚本显式做 id 重映射并落盘映射表；用官方评测工具对拍验证。
- 出处：OCHuman id 重映射（build_gt17.py）。

## 11. 下载/同步中断无断点续传

- 症状：大文件传输中断后从头再来，或静默丢文件。
- 根因：rsync 无 `--partial --timeout`；网络抖动（Tailscale）时裸跑。
- 修法：rsync 带 `--partial --timeout=300` + 重试循环；重试前先 `ssh 探活`；完成后零增量校验。
- 出处：2026-09-28 归档 SECTION_A 超时中断，MPII 23G 成空目录缺口。

## 12. 硬链接场 vs 复制

- 症状：同一批图片为多任务复制多份，磁盘爆炸。
- 根因：没规划存储布局。
- 修法：多视角/多任务共享图片用硬链接场（ln 不占额外空间），派生集只存标签；删除时注意硬链接语义。
- 出处：PoseTrack 硬链接场 20161 图。
